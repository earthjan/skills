# Decisions

The reasoning code doesn't preserve — one entry per non-obvious choice. Append-only; never edit a past entry to reflect current thinking, add a new one and cross-reference.

## YYYY-MM-DD — <short decision title>

**Context**: what problem/tradeoff forced a choice.

**Decision**: what was chosen.

**Why**: the reasoning — including options rejected and why. This is the part that gets lost on compaction/reset if it isn't written down here.

**Revisit if**: the condition under which this decision should be reconsidered (or "N/A" if none).
