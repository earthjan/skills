# ticket-effort — Default Model

The default is **Sonnet 5 at `medium`** effort for anything needing real judgment, and **Haiku 4.5 at `low`** for mechanical, well-specified work. Everything routes to one of those two unless a higher rule applies — Opus 5 is an escalation that requires a stated reason (real ambiguity, an undiagnosed hard bug, an architecture or integrity decision), never a default.
